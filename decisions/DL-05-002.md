# DL-05-002: HTTP ve test katmanında sıfır dış bağımlılık (node:http + node:test)

- Tarih: 2026-07-27
- Faz: 5 — Mimari Tasarım
- Mod: AUTOPILOT
- Karar: HTTP sunucusu `node:http` ile elle yazılan küçük bir router üzerinden kurulur (3 uç: `POST /api/shorten`, `GET /:code`, `GET /health`); testler `node:test` + `:memory:` DB ile koşar. Hiçbir npm çalışma-zamanı bağımlılığı eklenmez.
- Değerlendirilen alternatifler: Express/Fastify + Jest/Vitest (olgun router, middleware, zengin assert/mock).
- Gerekçe: Yüzey 3 uçtan ibaret; framework'ün getirdiği router/middleware değeri burada ~40 satırlık kodla karşılanıyor. Faz 4'te seçilen `node:sqlite` zaten stdlib olduğu için sıfır-bağımlılık hedefi bütün oluyor: `npm ci` adımsız, tedarik zinciri yüzeyi yok, Docker imajı `node_modules`'suz küçük ve tekrarlanabilir. Jest/Vitest ayrıca transpile/config yükü getirir; `node:test` NFR-1 süre ölçümü ve `:memory:` izolasyonu için yeterli.
- Riskler: Elle router'da yol eşleme/hata gövdesi hataları framework'ün verdiği güvenceyi kaybettirir → tüm uçlar (404, 400, 405) entegrasyon testiyle kapsanır; body-size limiti elle konur (Faz 7 güvenlik girdisi).
- Geri alınabilirlik: Yüksek (handler imzaları `(req,res)` olduğu için Express'e taşıma sarmalayıcı düzeyinde kalır)
- İnsan onayı: Otomatik

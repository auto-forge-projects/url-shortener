# DL-09-002: REQ-002 delta — BASE_URL yoksa short_url hiç dönmez

- Tarih: 2026-07-31
- Faz: 9 — Development (↺ cycle 3, REQ-002)
- Mod: AUTOPILOT
- Karar: `src/server.js` `require.main===module` yolunda `BASE_URL` için `http://localhost:${port}` fallback'i kaldırıldı (artık yoksa boş string). `src/create-handler.js` `baseUrl` falsy ise yanıttan `short_url` alanını tamamen çıkarıp yalnız `{ code }` döner — DL-06-001'in zaten karar bağladığı ama kodun hiç implemente etmediği sözleşme (Faz 6→9 contract drift) böylece uygulanmış oldu. Regresyon testi eklendi (`tests/create-handler.test.js`: "no BASE_URL -> code only, no short_url").
- Değerlendirilen alternatifler: (a) `localhost` fallback'ini prod domain'e sabit kodlamak — reddedildi, ortam-bağımlı değeri koda gömmek deploy'lar arası taşınamaz kılar; (b) `BASE_URL` yoksa 500 döndürmek — reddedildi, DL-06-001 zaten "yalnız code dönsün" demişti, gereksiz sertlik.
- Gerekçe: Kök neden kod-kanıtlı (docs/00-idea-v3.md): prod'da `BASE_URL` hiçbir katmanda set edilmiyordu, dönen `short_url` her zaman `http://localhost:3000/<code>` idi — dışarıdan erişilemez. Faz 12 tarafı (deploy/remote-deploy.sh `-e BASE_URL=https://${HOST}`) tamamlayıcı yarı: gerçek domain set edildiğinde artık düzgün çalışan short_url üretilir; kod tarafı yalnız "yanlış link verme" davranışını garanti eder.
- Riskler: Mevcut istemciler (varsa) `short_url` alanının her zaman geleceğini varsaymış olabilir — API henüz yayında/gerçek istemcisi olmadığından (MVP) etkisi yok; Faz 15/16'ya not düşüldü.
- Geri alınabilirlik: Yüksek (tek koşullu ifade, adaptör sınırında).
- İnsan onayı: Otomatik
- Varsayım mı?: Hayır — kök neden statik kod kanıtıyla doğrulandı, varsayım gerekmedi.
